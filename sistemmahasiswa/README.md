# Sistem Penilaian Mahasiswa

Sistem web sederhana untuk menampilkan dan menghitung nilai mahasiswa secara profesional.

## Fitur
- Tabel data mahasiswa
- Perhitungan nilai akhir otomatis
- Penentuan grade dan status lulus/tidak
- Statistik kelas (rata-rata, nilai tertinggi, jumlah lulus/tidak)
- Desain modern dark mode

## Cara Menjalankan
1. Pastikan PHP sudah terinstall
2. Jalankan di terminal:
   ```bash
   php -S localhost:8000
   ```
3. Buka browser ke http://localhost:8000/sistemmahasiswa
